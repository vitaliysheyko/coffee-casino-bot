# Coffee Casino Bot — Host Assistant

## Концепция

Бот — **помощник ведущего** (Host Assistant), а не замена игры или игровой интерфейс для участников.

**Принципы:**
- Физическая игра первична: стол, фишки, сукно, кофе, вкус, общение
- Игроки не должны отвлекаться на телефоны во время игры
- Бот помогает ведущему: сценарий, таймер, подсчёт, PDF поля
- Единственный ввод от ведущего во время игры — отметить кто угадал

## Целевой UX-флоу

### ДО ИГРЫ (подготовка)
1. Ведущий создаёт лоты (пакетно: JSON/CSV-импорт, шаблоны, пресеты)
2. Ведущий создаёт игру: задаёт число раундов, таймер, стартовые фишки
3. Бот генерирует PDF игрового поля для печати (категории ставок по лотам)
4. Бот даёт ссылку на веб-таймер для проектора

### ВО ВРЕМЯ ИГРЫ
- Бот даёт ведущему **сценарий каждого раунда** (текстовые подсказки что говорить/делать)
- Таймер отображается на проекторе (веб-страница)
- После каждого раунда ведущий вручную отмечает кто угадал → бот считает фишки
- Турнирная таблица обновляется автоматически

### ПОСЛЕ ИГРЫ
- Бот объявляет победителя, генерирует итоговую таблицу
- Сохраняет историю игры в БД

## Что поменяется относительно текущего кода

| Компонент | Сейчас | Станет |
|-----------|--------|--------|
| Интерфейс игрока | Глубокие ссылки, кнопка «я сделал ставки» | Игроки не взаимодействуют с ботом вообще |
| Модель GamePlayer | has_bet | is_correct_country, is_correct_region, ... |
| Модель Game | status, timer | + round_results, leaderboard snapshot |
| Лоты | Создание по 1 через wizard | + импорт JSON/CSV |
| Game flow | FSM с авто-рефрешерами | Скриптовый движок с подсказками ведущему |
| Reveal | Текст всем игрокам | Результаты ввода от ведущего → подсчёт → таблица |
| Таймер | Сообщение в чате | + Веб-ссылка для проектора |
